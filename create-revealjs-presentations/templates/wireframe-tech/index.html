Code Snippet


// Create wireframe torus geometry
const geometry = new THREE.TorusGeometry(2, 0.6, 16, 100);
const material = new THREE.MeshBasicMaterial({
  color: 0x00ffff,
  wireframe: true
});

// Add to scene and animate
const torus = new THREE.Mesh(geometry, material);
scene.add(torus);

// Rotation animation
torus.rotation.x += 0.01;
torus.rotation.y += 0.005;
The wireframe torus is created with just a few lines of Three.js code. Rotation values can be adjusted for different animation speeds.
